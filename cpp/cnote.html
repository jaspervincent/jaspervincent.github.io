MIMIORPG的10个套路

游戏系统设计

  1. 战斗系统：（底层：属性之间的比拼），只要把属性系统做好就行了
    1. Pvp：玩家和玩家之间的战斗
    2. pve：玩家和野怪之间的战斗
  2. 属性系统：攻击、防御、命中、闪避、暴击、暴防，战斗时是这些数值的比拼。这些数值通过升级获得，所以把等级系统做好就行了
    • 命中概率 = 攻击方命中 / (攻击方命中 + 防御方闪避)
    • 暴击概率 = 攻击方暴击 / (攻击方暴击 + 防御方暴防)
    • 基础伤害 = 攻击方攻击 * (1 + 暴击倍率加成)

    • 最终伤害 = 基础伤害 * (100 / (100 + 防御方防御))

  3. 等级系统：给他一个目标，玩家就会意识到只要等级提升能力就会变强，就能持续玩下去。怎么升级？打怪获取经验。只要把经验系统做好就行了。

  4. 经验系统：每升一级需要不同的经验，按照固定系数增长对应的属性。但是如果每个人系数一样，那么相同等级的玩家属性也是一样的呀！除了升级获得属性外，还需要额外增加属性的载体，它可以穿在玩家身上的，姑且叫它为装备吧。所以只要把装备系统做好就行了。 

    def get_exp_required(level):
 if leve <= 30:
     # 30 级及以下：基础线性增长，升级难度低
     exp = 100 * level + 500
 elif 30 < leve < 50:
     # 30-49 级：中等增长，难度提升
     exp = 2000 * (level - 20) + 2000
 else: # 50 <= level < 100
     # 50-99级：高速增长，升级难度大福提升
     exp = 6000*(level - 30) + 10000
 # 返回整数经验数
 return int(exp)
  5. 装备系统：装备有穿戴等级限制，装备有基础属性和扩展属性，装备星级。装备怎么来？刷怪掉。所以只要把掉落系统做好就行了。
    • 攻击性装备：武器、护腕、戒指、护符
    • 防御性装备：头盔、甲胃、手套、鞋子、护肩、腰带
    • 攻防兼备：项链、暗器、龙纹、令牌
    • 基础属性：属性条数固定
    • 扩展属性：属性条数随机、条数越多品质越高，白绿蓝紫橙金红
    • 装备星级：星级越高属性数值越大，确保组合足够多，这样玩家装备一样的概率低。

  6. 掉落系统：掉好东西的场景一定要做成可以pk的。所以一定要做好氪金系统。

    满足3要素

    • 越难打的怪，掉的东西越好。玩家会不断提升装备
    • 掉落加入概率：要有惊喜感
    • 昭告天下：极品装备。
  7. 氪金系统：核心材料还是商城买的。所以只要把商城系统做好就行了。
    • 6 元做为首充：性价比最高。然后30、98、198、328、648，再送些材料，6 元的材料需要挂机一周。不充钱没问题，但是电费要自己交的。
  8. 商城系统：商城货币充值获得。做成可交易的，把交易系统做好就行了。
  9. 交易系统：白漂玩家就是充钱玩家的游戏体验。不会让你把装备这么容易做出来，所以把锻造系统做好就行了。
  10. 锻造系统：想锻造出极品装备，不管钱多少也需要花费大量时间成本。因为如果有钱就是可以为所欲为，他可能爽完就流失了，所以必需让他即花钱又花时间，时间的沉没成本远比RMB更弥足珍贵。事实上时间才是最珍贵的，一寸光阴一寸金，寸金难买寸光阴。装备系统做完可以开宝石系统。
  11. 宝石系统：攻击宝石、防御宝石、命中宝石、闪避宝石、暴击宝石、暴防宝石。宝石还可以升级，根据服务器大佬的消费水平看是否开放更高级的。当然可以设置
    • 资质系统：给装备的基础属性增加百分比数值
    • 铭刻系统：给装备的基础属性增加10%
    • 强化系统：给装备的基础属性增加百分比数值，强化等级总共99级，每级都有概率
    • 雕吻系统：依附于装备上的另一种物品，共10级，利用天蚕丝进行升级
    • 精东系统：给装备增加三个新扩展属性
    • 天刀系统：给装备的扩展属性增加百分比数值。
