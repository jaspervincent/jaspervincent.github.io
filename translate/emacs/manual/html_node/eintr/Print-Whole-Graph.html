C.4 打印完整图表 ¶

现在我们几乎已经准备好打印完整图表了。

打印带正确标注的图表的函数遵循我们之前创建的结构（see A Graph with Labeled Axes），但有所扩充。

结构如下： 

(defun print-graph (numbers-list)
  "documentation..."
  (let ((height  ...
        ...))

    (print-Y-axis height ... )
    (graph-body-print numbers-list)
    (print-X-axis ... )))
