1.8.3 可变数量参数 ¶

有些函数（如 concat、+ 或 *）可以接受任意数量的参数。（* 是表示乘法的符号。）你可以按常规方式对下面每个表达式求值，回显区中出现的结果会在本文中以 ‘⇒’ 标注，可理解为“求值结果为”。

第一组中，函数不带任何参数： 

(+)       ⇒ 0

(*)       ⇒ 1

这一组中，每个函数各带一个参数： 

(+ 3)     ⇒ 3

(* 3)     ⇒ 3

这一组中，每个函数各带三个参数： 

(+ 3 4 5) ⇒ 12

(* 3 4 5) ⇒ 60
