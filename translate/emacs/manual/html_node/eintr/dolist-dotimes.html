11.2 省时利器：dolist 与 dotimes ¶

除了 while，dolist 和 dotimes 也可用于实现循环。有时它们比等价的 while 循环更易编写。 两者都是 Lisp 宏。（详见 Macros in The GNU Emacs Lisp Reference Manual。）

dolist 的行为类似于不断取 CDR 遍历列表的 while 循环： 每次循环时，dolist 会自动缩短列表（取列表的 CDR）， 并将每个更短列表的 CAR 绑定到它的第一个参数。

dotimes 则会循环指定次数：由你指定循环次数。
