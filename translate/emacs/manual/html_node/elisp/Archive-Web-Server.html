44.5 与归档 Web 服务器对接 ¶

提供软件包归档访问的 Web 服务器必须支持以下查询：

archive-contents

返回描述归档内容的 Lisp 表达式。该表达式为 ‘package-desc‘ 结构列表（参见 package.el），列表首个元素为归档版本。

<package name>-readme.txt

返回该软件包的详细描述。

<file name>.sig

返回对应文件的签名。

<file name>

返回文件本身。多文件软件包为 tar 包，单文件软件包为独立文件。
