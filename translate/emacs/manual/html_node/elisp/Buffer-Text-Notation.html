1.3.6 缓冲区文本表示法 ¶

有些示例会通过展示文本修改前后的状态，来描述对缓冲区内容的改动。这类示例会把对应缓冲区的内容，放在两行包含缓冲区名称的虚线之间。此外，‘∗’ 用来表示光标位置（point）。（当然，光标标记并非缓冲区里的实际文本；它只是标识出当前光标位于哪两个字符之间。） 

---------- Buffer: foo ----------
This is the ∗contents of foo.
---------- Buffer: foo ----------

(insert "changed ")
     ⇒ nil
---------- Buffer: foo ----------
This is the changed ∗contents of foo.
---------- Buffer: foo ----------
