22 命令循环 ¶

当你运行 Emacs 时，它几乎会立即进入 编辑器命令循环(editor command loop)。 该循环读取按键序列，执行其定义，并显示结果。 本章将描述这些过程的实现方式，以及允许 Lisp 程序完成这些操作的子例程。
