20 Lisp 对象的读取与打印 ¶

打印(Printing)与 读取(reading) 是将 Lisp 对象与文本形式相互转换的操作。 它们使用的文本表示与读取语法已在 Lisp 数据类型 中说明。

本章介绍用于读取和打印的 Lisp 函数，同时也介绍 流(streams) —— 用于指定从哪里获取文本（读取时）或向哪里输出文本（打印时）。
