22.8 读取输入 ¶

编辑器命令循环通过函数 read-key-sequence 读取按键序列，该函数内部会调用 read-event。这些事件输入相关函数也可在 Lisp 程序中直接使用。另请参见 临时显示 中的 momentary-string-display，以及 等待时间流逝或输入 中的 sit-for。关于控制终端输入模式和调试终端输入的函数与变量，详见 终端输入。
