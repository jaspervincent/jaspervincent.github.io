42.4 回显区 ¶

回显区(echo area) 用于显示错误信息（see 错误）、通过 message 原语产生的提示信息，以及回显按键操作。它与小缓冲区并非同一概念，尽管小缓冲区激活时会出现在屏幕上与回显区相同的位置。See The Minibuffer in The GNU Emacs Manual.

除本节介绍的函数外，你还可以通过将 t 指定为输出流，将 Lisp 对象打印到回显区。See 输出流。
