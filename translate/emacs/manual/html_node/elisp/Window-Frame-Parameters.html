30.4.3 窗口框架参数 ¶

一个框架具体包含哪些参数，取决于它所使用的显示机制。 本节介绍在部分或所有终端上具有特殊含义的参数。 其中，name、title、height、width、 buffer-list 和 buffer-predicate 在终端框架中有效； 而 tty-color-mode 仅对文本终端框架有效。
