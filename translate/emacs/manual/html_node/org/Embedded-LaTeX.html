12.5 Embedded LaTeX ¶

纯 ASCII 通常足以满足绝大多数笔记需求，例外情况是科研笔记，这类内容常需要数学符号与公式。LaTeX113 是广泛用于排版科技文档的工具。Org mode 支持嵌入 LaTeX 代码，一方面因为许多科研人员习惯读写 LaTeX 源码，另一方面它可被轻松处理，为多种导出后端生成精美输出。
