13.9.1 HTML export commands ¶

C-c C-e h h (org-html-export-to-html) ¶

导出为后缀为 ‘.html’ 的 HTML 文件。对于 ‘myfile.org’ ，Org 会导出为 ‘myfile.html’ ，覆盖时不会提示。C-c C-e h o 会导出 HTML 并在网页浏览器中打开该文件。

C-c C-e h H (org-html-export-as-html) ¶

导出到临时缓冲区，不会创建文件。
