13.16 Other Built-in Backends ¶

Org 内置的其他导出后端包括：

  • ‘ox-man.el’: 导出为手册页格式。

如需激活此类后端，可自定义 org-export-backends ，或通过 ‘(require 'ox-man)’ 直接加载。加载成功后，后端会在导出调度器中添加新按键（见 The Export Dispatcher）。

使用方法与配置细节可参考对应文件的注释部分，例如 ‘ox-man.el’ 。
