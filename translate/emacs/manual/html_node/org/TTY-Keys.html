17.15 Using Org on a TTY ¶

Org 为无法对光标执行移动指令，以及无法使用带修饰键按键绑定的终端和现代移动设备，提供了备用按键绑定。其中部分替代方案可能会略显繁琐。用户可根据自身使用需求进一步自定义这些设置。例如，编辑时间戳常用的 S-<cursor>，改用组合键 C-c . 会更合适。
